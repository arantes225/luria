## 2026-10-27 - Enhance global button keyboard accessibility\n**Learning:** The base button class in this vanilla HTML/CSS stack lacked a generic  pseudo-class for keyboard navigation, making it hard to see which UI component was active when tabbing through menus and auth screens. This change affects every page gracefully without negative side effects since it only targets users explicitly tabbing via keyboard.\n**Action:** Always search the root stylesheets (e.g. `assets/css/style.css`) for global element resets and ensure base UI components like `.button` and `.input` have a generic `:focus-visible` class defined instead of hunting for specific page elements.
