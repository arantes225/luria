Criar apostila

A capa é escolhida automaticamente pela área.
A capa-base é sempre crua. Ao gerar uma apostila, use area apenas para escolher o modelo, materia como subárea e tema como tema específico. O texto é aplicado sobre a arte com fundo totalmente transparente. O JSON também deve apontar para a capa com cover_key. Valores aceitos: clinica_medica, cirurgia_geral, ginecologia_obstetricia, pediatria e medicina_preventiva. Se cover_key vier ausente, o sistema resolve automaticamente a partir da área.
