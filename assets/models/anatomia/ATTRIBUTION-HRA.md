# Human Reference Atlas (HuBMAP) — Atribuições e Licenças

Os modelos anatômicos de referência do coração, rins, mamas e sistema reprodutor foram adaptados a partir do **Human Reference Atlas (HRA) / HuBMAP**:
- **Autores / Equipe:** Kristen Browne, Heidi Schlehlein, et al., HuBMAP Consortium.
- **Biblioteca:** 3D Reference Library v1.10 (https://humanatlas.io/3d-reference-library).
- **Licença:** [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).

### Modificações Realizadas
- Simplificação e otimização geométrica para renderização em tempo real no navegador via WebGL/Three.js.
- Segmentação e atribuição de IDs didáticos em língua portuguesa para identificação de estruturas anatômicas.
- Ajuste de cores para diferenciação didática de camadas e vasos.
- Uso estritamente educacional; não se destina a planejamento cirúrgico ou diagnóstico clínico assistencial.
